Base URL: https://api.firstcall.local

Create note
POST /v1/customers/{customer_id}/notes

Authentication: Bearer token in the Authorization header.

Required field `note`
Required field `source`

Example request body:
```json
{
  "note": "{{note}}",
  "source": "firstcall"
}
```

Example curl:
```bash
curl https://api.firstcall.local/v1/customers/{{customer_id}}/notes \
  -X POST \
  -H 'Authorization: Bearer {{bearer_token}}' \
  -H 'Content-Type: application/json' \
  -d '{"note":"Reached by phone","source":"firstcall"}'
```
